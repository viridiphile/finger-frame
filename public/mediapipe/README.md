# Local MediaPipe assets

- `hand_landmarker.task`: Google's Hand Landmarker **float16, version 1** bundle.
- Source: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
- SHA-256: `fbc2a30080c3c557093b5ddfc334698132eb341044ccee322ccf8bcf3607cde1` (recorded from the downloaded artifact).
- Model documentation: https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/index
- Library: `@mediapipe/tasks-vision` **1.1.0**, [MediaPipe](https://github.com/google-ai-edge/mediapipe), Apache-2.0 according to the package metadata.
- `wasm/`: generated by `scripts/prepare-assets.mjs` from that exact npm package before dev/build. The generated six runtime files are ignored in source control but included in the production output. Do not mix runtimes from different package versions.

Restore a missing/corrupted model with `npm run setup:model`. The downloader verifies the recorded SHA-256 before replacing the artifact. Dev/build fail with guidance if the model cannot be verified, avoiding a successful-looking build that silently lacks tracking assets.

These assets are served from the app origin; webcam frames are not sent to Google or a CDN.
